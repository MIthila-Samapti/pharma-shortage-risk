Which drugs have only one or two makers left?

The shortage lookup above only scores drugs already on FDA's shortage list. This reads the full NDC directory instead - every finished human drug product FDA has on file - to flag ones with just one or two labelers, before any shortage is reported.

This is a structural fragility score, not a forecast. A drug can sit at one maker for years with no problem. "Labeler" also isn't always "manufacturer" - the directory lists whoever is legally responsible for a listing, which can be a repackager reselling someone else's product. Single-source (exactly one labeler) is the more reliable tier; dual-source is next; above that isn't flagged here at all.

What this reads

The complete FDA NDC (National Drug Code) directory - not just drugs already in shortage. Grouped by generic name and dosage form, then counted by distinct labeler, after collapsing obvious name variants of the same company (e.g. "Acme Pharma" and "Acme Pharma, Inc.").

02

Why this exists

The shortage model above already found that supplier concentration is the strongest signal for telling a real shortage from a discontinuation notice - but only among drugs already in shortage. This page asks the harder question: of drugs NOT yet in shortage, which ones have the least redundancy if one maker stopped?

!

Limitations

Not every remaining NDC listing is still actually being made and sold - FDA doesn't guarantee that. A low labeler count is a real signal, not a certainty, and this says nothing about when or whether a shortage will actually happen. Not a substitute for official FDA guidance.
